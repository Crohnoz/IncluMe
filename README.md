# IncluMe

Plataforma de accesibilidad urbana para encontrar, documentar y revisar estacionamientos accesibles en Chile.

## Accesos rápidos

| Acceso | Enlace | Uso |
| --- | --- | --- |
| Aplicación ciudadana | [Abrir IncluMe](https://inclume-chile.netlify.app/) | Mapa, búsqueda y aportes comunitarios |
| Portal municipal | [Abrir demo municipal](https://inclume-municipalidades.netlify.app/) | Indicadores, revisión territorial y exportación |
| Reportar o corregir | [Abrir formulario](https://inclume-chile.netlify.app/feedback/) | Informar un punto nuevo o corregir información |
| Consultar estado | [Abrir seguimiento](https://inclume-municipalidades.netlify.app/estado/) | Revisar el estado de un envío |
| GitRaw ciudadano | [Abrir previsualización](https://raw.githack.com/Crohnoz/IncluMe/master/preview-v2/index.html) | Respaldo estático para desarrollo |
| GitRaw municipal | [Abrir previsualización](https://raw.githack.com/Crohnoz/IncluMe/master/preview-v2/municipalidades.html) | Respaldo estático para desarrollo |

> **Acceso principal:** Netlify. Las vistas GitRaw se conservan únicamente como previsualizaciones alternativas del repositorio.

## Código y despliegues

- Repositorio: [Crohnoz/IncluMe](https://github.com/Crohnoz/IncluMe)
- Rama ciudadana: `netlify-ciudadania`
- Rama municipal: `netlify-municipalidades`
